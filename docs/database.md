# AI Alchemist Database Schema

AI Alchemist relies on the following core data tables within the Lemma Pod.

## Core Tables

- `resumes`: Stores uploaded documents and parsed JSON metadata (`parsed_skills`, `score`).
- `jobs`: Stores saved and scraped job descriptions (`match_score`, `company`, `status`).
- `applications`: Tracks the pipeline state (`applied_date`, `status`, `match_score`).
- `interviews`: Logs upcoming scheduled interviews (`type`, `scheduled_at`, `status`).
- `career_scores`: The aggregated user metrics (`readiness`, `resume`, `ats`).
- `career_tasks`: Actionable roadmap items generated by the Career Planner (`priority`, `completed`).
- `notifications`: Push alerts for the user (`message`, `read`).
